# Interfaz web

Michelle desarrolla las [vistas Blade](../resources/views/) y sus archivos estáticos. Para comenzar, el listado móvil puede leer el [ejemplo ficticio](../datos/ejemplos/establecimientos.json) y presentar cada estado del [contrato inicial](contrato-establecimientos.md).

La vista del mapa usará Google Maps JavaScript API y mostrará los comercios con coordenadas. Los comercios pendientes de ubicación seguirán disponibles en el listado. Mantener la lectura de datos separada de la pantalla permitirá cambiar del ejemplo ficticio a la API cuando esté disponible.
