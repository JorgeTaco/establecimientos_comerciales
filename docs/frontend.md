# Interfaz web

Michelle desarrolla las [vistas Blade](../resources/views/) y sus archivos estáticos. En `/establecimientos`, el listado móvil consulta la búsqueda ampliada de Laravel. Si la API está vacía o falla, usa el ejemplo ficticio e indica el origen. La [guía de integración](integracion-piloto.md) explica cómo conectar las siguientes pantallas.

La vista del mapa usa Maps JavaScript API y muestra los comercios con coordenadas. Los comercios pendientes de ubicación siguen disponibles en el listado.
